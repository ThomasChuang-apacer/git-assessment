REPOSITORY GUIDE

如何開始操作題目？

進入任一題後，可以用下列任一種方式開啟該題的 Repository。Git 指令必須在這個資料夾中執行。

1

複製地址，再使用 cd

在題目頁按「複製地址」，開啟 CMD 或 PowerShell，輸入下列指令並貼上剛才複製的地址：

cd "貼上剛才複製的地址"
2

開啟資料夾，再從網址列開啟 CMD

在題目頁按「開啟資料夾」，點擊檔案總管上方的網址列，輸入 cmd 後按 Enter，即可直接在該資料夾開啟 CMD。

3

使用 VS Code 操作

在 VS Code 選擇「檔案 → 開啟資料夾」，貼上題目頁顯示的地址並開啟。若已安裝 code 指令，也可在該資料夾的 CMD 輸入 code .。

完成 Git 操作後，回到題目頁按「檢查結果」。
