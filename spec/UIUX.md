# Git 實作考試系統 UI/UX 設計規範

文件版本：2.1
更新日期：2026-11-25
適用架構：Flask 本機 Web Server + Jinja2 模板 + Vanilla JS/CSS（完全離線無外部依賴）

---

## 一、設計原則與離線限制

1. **完全離線可用**：不使用任何 CDN、Google Fonts、外部 CSS/JS 或外部圖片；圖示與 favicon 皆採內嵌 SVG 或純 CSS 繪製。
2. **系統字型堆疊**：
   - 中文與介面內文：`"Microsoft JhengHei", "PingFang TC", "Noto Sans TC", system-ui, sans-serif`
   - 程式碼、路徑與標籤：`Consolas, "Cascadia Code", "Courier New", monospace`
3. **開發者工具風格**：高對比淺灰背景（`#f3f5f7`）搭配白底卡片（`#ffffff`）、專業藍強調色（`#0369a1`）、成功綠（`#237a49`）、錯誤紅（`#a9362b`）及終端機炭黑區塊（`#20252b`）。
4. **語意與無障礙**：
   - 任何狀態（成功、失敗、進行中、警告）不可只靠顏色區分，必須同時搭配符號（`✓`、`✗`、`!`、`·`）與明確文字說明。
   - 所有互動元件具備清楚的 `:focus-visible` 外框，動畫遵守 `prefers-reduced-motion: reduce`。
   - 操作確認一律使用統一風格的 `<dialog id="confirm-dialog">`，不以原生 `window.alert` / `window.confirm` 作為主要互動界面。

## 二、核心頁面結構與互動規範

### 1. 共用導覽列（`base.html`）
- 左側品牌標誌 `G Git 實作測驗` 連結回首頁。
- 右側依頁面顯示身份／返回連結、「考官模式」入口（啟用 PIN 且未解鎖時於頁首隱藏）與「安全關閉 Git Assessment」按鈕（具備明確說明提示，關閉後顯示「已安全關閉 Git Assessment」確認畫面）。
- 內嵌 SVG favicon 避免產生無謂的 `/favicon.ico` 404 紀錄。

### 2. 首頁（`home.html`）
- **左欄（說明與須知）**：標題、六題涵蓋範圍簡介與簡潔「測驗須知」卡片。
- **右欄（環境檢查與建立表單）**：
  - Git、題目環境、儲存狀態 3 項即時檢查燈號（異常時提供前往處理連結）。
  - 同瀏覽器有未完成紀錄時顯示「繼續上次測驗」引導塊。
  - 姓名欄位前端即時 `.trim()` 與 80 字元檢查，於欄位下方 inline 顯示錯誤訊息並同步 `aria-invalid`，不因純空白跳離頁面。
  - 提供「練習模式」與「考試模式」單選選項（使用明確 `for`/`id` 與 `aria-labelledby`/`aria-describedby` 宣告中文名稱與說明）。
- **下方歷史區**：顯示格式化本地時間（`YYYY/MM/DD HH:MM:SS`）、測驗模式徽章、需修復警示徽章；已完成項目「查看結果」直接連往 `/result` 頁面；啟用考官 PIN 時自動隱藏他人紀錄。

### 3. 任務總覽與操作指南（`overview.html`、` _repository_guide.html`）
- 顯示 `X / 6` 進度面板與 3×2 卡片網格（手機降為 1 欄、平板 2 欄）。
- 卡片右上角細分「✓ 已完成」「進行中」「已開啟」「尚未開始」，底部顯示上次檢查通過項數（不將 `waiting` 前置項目誤計為通過）。
- 全數完成且無損壞題目時，頂部綠色橫幅直接提供「查看／保存結果 →」主按鈕。
- `? 如何開始` 使用 `<dialog>` 彈窗，統一「複製路徑」術語並附帶編輯器（Vim `:wq` / `--no-edit`）與重設防呆說明。

### 4. 題目作答頁（`task.html`）
- **左欄**：`整體進度 X / 6 題完成` 徽章、適度縮放的標題字級（避免中等寬度斷行過碎）、情境說明、深色 Repository 路徑卡（置頂於步驟之前，支援長路徑自動換行，並就近顯示複製／開啟資料夾訊息）、依模式切換「任務要求」或「任務目標」、模擬遠端操作（含按鈕停用狀態與就近提示）、操作限制與按需動態載入的「操作提示（計次，考試模式展開前彈窗確認）」。
- **右欄（黏性檢查面板）**：顯示通過摘要與累計檢查／重設／修復次數、狀態符號（`✓` / `!` / `·`）、區分 `passed` / `failed` / `waiting` 的條件列表（考試模式下隱藏具體指令名稱）、完成後顯示「前往下一題 → / 查看／保存結果 →」主按鈕；行動版捲動離開右欄時於底部浮出 `check-dock`。

### 5. 結果摘要頁（`result.html`）、錯誤頁（`error.html`）與考官控制台（`examiner.html`）
- **結果頁**：頭像維持深底亮藍高對比字色；分行呈現開始／完成時間、總作答時間、模式、檔案一致性校驗碼；每題列出檢查次數、重設次數、修復次數、提示次數與耗時（缺少開始時間時顯示 `—`）；支援可展開操作時間軸、「複製文字摘要」與「保存成 PNG」（含完成時間與防姓名溢位）。
- **錯誤頁**：將具體錯誤原因直接作為主標題 `<h1>` 顯示，方便即時辨識原因。
- **考官控制台**：支援 PIN 碼鎖定／解鎖（錯誤採 PRG 導回並附錯誤嘗試鎖定保護）、全體紀錄與檔案一致性總表、一鍵修復／刪除，以及清理 `quarantine/` 與舊版殘留檔工具。
